# EMS 기준정보 관리 (프론트 프로토타입)

에너지 모니터링 시스템(EMS)의 기준정보 관리 체계를 더미 데이터로 확인하는 프론트엔드 프로젝트입니다. 백엔드·DB는 다음 단계입니다.

## 화면 (온보딩 순서)
| 단계 | 화면 | 하는 일 |
|---|---|---|
| 1 | 기준 코드 | 단위·설비 유형 등 공통 코드와 사이트 고유(LOC_) 코드 |
| 2 | 파라미터 관리 | 설비·템플릿 등록, 원천 태그 가져오기(CSV)·매핑·승인(승인하면 설비 항목에 바로 연결), 약어 사전 |
| 3 | 계통 트리 설계 | 전력·조직·공간 뷰별 노드 추가·수정·이동·삭제, 경로 코드 자동 생성 |
| 4 | 트리 매핑 | 설비를 노드에 배치(즉시 반영), 배분율, 뷰 간 경로 비교 |
| 5 | 점검 | 누락·불일치 점검표(막지 않고 알려줌), 점검 기준, 변경 이력 |

입력 단계에서 막는 것: 단위·이름 누락 승인, 같은 설비 항목 중복 연결, 같은 설비 내 포인트명 중복, 형식이 틀린 코드, 사용 중인 노드·설비 삭제. 되돌리기는 사이드바 버튼(최근 30단계, 새로고침 전까지).

모든 화면은 하나의 시드(`src/domain/seed.ts`)와 하나의 스토어를 공유하며, 경로 코드·충족도·점검 결과는 저장하지 않고 매번 계산합니다. 태그와 배치는 설비를 코드가 아닌 내부 ID로 참조합니다. 상태 변경은 `src/domain/actions.ts`의 순수 함수입니다.

## 실행
```
npm install
npm run dev        # 개발 서버
npm test           # 화면 간 연동 테스트
npm run build
```
변경 내용은 브라우저 localStorage에만 저장되며, 화면 왼쪽 아래 버튼으로 초기화할 수 있습니다.

설계 배경은 `docs/EMS_기준정보_관리체계_설계안.md`를 참고하세요. 데이터는 모두 샘플이며 실제 사이트 정보가 아닙니다.
