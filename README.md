# HD현대일렉트릭 CEMS 기준정보 관리 (프로토타입)

EMS 온보딩용 기준정보 관리 화면의 프런트엔드 프로토타입입니다. 서버·DB 없이 더미 데이터로 동작하며, 데이터는 브라우저 localStorage에 저장됩니다(백엔드/로컬 DB 연동은 다음 단계).

## 작업 순서 (메뉴 5개)

1. **코드 관리** — 코드 테이블(파라미터·단위·설비 유형·에너지원·그룹 유형)을 고르고 그 안의 코드(코드·코드명·약자·설명)를 관리합니다. 테이블별 로컬 접두사·코드 형식, 파라미터의 기본 단위·복수 허용·합산 대상, 그리고 설정(포인트 ID 형식, 합산 허용 오차)도 여기서 정합니다.
2. **수집 태그** — 수집 태그(raw)에 파라미터·단위를 지정합니다.
3. **트리 설계** — 설비를 등록하고 전력계통·조직·공간 트리에 배치합니다. 트리별로 "모든 설비 배치 필수", "합산 점검"을 켜고 끕니다. 경로 코드는 자동 생성됩니다.
4. **포인트 매핑** — 정리된 태그를 설비에 연결하면 포인트 ID·포인트명이 만들어집니다.
5. **점검** — 누락·중복·단위 불일치·합산 차이를 확인하고 변경 이력을 봅니다(작업을 막지 않음).

## 설계 원칙

- 로직에 특정 코드값을 박아 두지 않습니다(합산 대상은 파라미터 속성, 합산 점검·배치 필수는 트리 옵션, 접두사·ID 형식은 설정).
- 상태·경로 코드·포인트명·점검 결과는 저장하지 않고 항상 계산합니다.
- 태그·트리는 설비 내부 ID로 참조하므로 설비 코드를 바꿔도 연결이 유지됩니다.
- 입력 단계에서 오류를 막고(형식·중복·순환·삭제 보호), 일괄 작업은 전부 성공하거나 전부 취소됩니다.
- 되돌리기(최근 30건, 메모리 보관), 초기화 제공.

## 실행

```
npm install
npm run dev     # 개발
npm test        # 도메인 테스트
npm run build   # 배포 빌드
```
